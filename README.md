# TreoPlugin

Plugin Paper (1.21.x): `/treo` để treo AFK (đứng yên, thoát game vẫn còn người chơi giả online), `/huytreo` để hủy.

## Lấy file .jar
1. Đưa toàn bộ thư mục này lên GitHub.
2. Vào tab **Actions** → chọn lần chạy mới nhất → tải **TreoPlugin** ở mục Artifacts.
3. Giải nén, bỏ file `.jar` vào thư mục `plugins/` của server.

## Đổi phiên bản Minecraft
Sửa số phiên bản trong `build.gradle.kts` (dòng `paperDevBundle`). Mặc định: 1.21.4.
